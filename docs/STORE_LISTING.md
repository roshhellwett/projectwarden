## 4. Permission Justifications

| Permission | Developer Dashboard Justification |
|------------|-----------------------------------|
| `nativeMessaging` | Required for secure local IPC communication with the `zenith-passkeys-host` native background daemon to retrieve, sign, and store cryptographic passkey assertions in the user's local encrypted vault. |
| `storage` | Used exclusively to persist local UI preferences, auto-lock timeouts, and active session flags within the extension sandbox. |
| `activeTab` | Required to inspect the origin and relying party ID (RP ID) of the active browser tab when a website triggers a WebAuthn authentication or registration request, preventing credential theft and domain spoofing. |

## 5. Privacy Policy & Data Usage Disclosures

- **Does this extension collect user data?** **No.**
- **Does this extension make external network requests?** **No.** All WebAuthn credentials and vault data are processed completely offline on the user's local system.

### Privacy Policy Declaration (Ready to publish / host):
```markdown
# Privacy Policy for Zenith Passkeys
Last updated: September 2026
Publisher: Zenith Open Source Projects

Zenith Passkeys is an open-source, local-first WebAuthn passkey manager.

1. Data Collection & Processing
Zenith Passkeys does not collect, track, transmit, or share any personal information, browsing history, device identifiers, or cryptographic keys.

2. Local Storage & Encryption
All passkeys, credentials, and metadata are stored exclusively on your local computer inside an AES-256-GCM encrypted vault derived via Argon2id. Private keys are never transmitted over the internet or accessible to cloud services.

3. Third-Party Sharing
Zenith Passkeys does not integrate with any third-party advertising, analytics, or tracking SDKs. No data is ever sold or transferred.

4. Contact
For questions or security disclosures, please contact Zenith Open Source Projects at zenithprojects@icloud.com.
```
